# Sophis Central UI implementation notes

The frontend follows the supplied Brand & Product Guidelines:

- Foundation: Navy Blue `#091F5B`
- Primary interactive: Royal Blue `#004BEC`
- Depth/gradient: Indigo Blue `#2C36D9`
- AI/premium accent: Vibrant Purple `#6121D0`
- Canvas/content: Pure White `#FFFFFF`
- Main hero gradient: Royal Blue → Indigo
- Purple is reserved for AI/feature accents, not primary buttons
- Academic documents, forms, search results, tables and dashboards use solid white surfaces
- Footer and intentional dark panels use Navy Blue
- Primary actions use Royal Blue; secondary actions use white with a Royal Blue border
- Focus states remain visibly keyboard-accessible
- Status is not communicated by color alone
- Light mode is the product standard for academic readability
